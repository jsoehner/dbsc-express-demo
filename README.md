This project utilizes a suite of specialized AI skills to ensure high-quality software engineering, security, and architectural integrity.

- **ADR Authoring**: Drafting high-quality Architectural Decision Records (ADRs) with clear rationale and consequences.
- **Architecture Review**: Evaluating system designs for scalability, maintainability, and SOLID principles.
- **C4 Modeling**: Generating context, container, component, and code-level diagrams.

- **Code Refactoring**: Specialized clean code refactoring, reducing complexity and improving maintainability.

- **API Design**: REST, GraphQL, and OpenAPI 3.1 specification management.

### 🛡️ Security & Compliance
- **Security Auditing**: Comprehensive security audits, SAST (Semgrep, CodeQL), and threat modeling (STRIDE).

### 📊 Data Engineering & ML

- **MLOps**: End-to-end machine learning pipelines, model serving, and experiment tracking.

### 📝 Documentation & Communication
